# Live Translate

Real-time AI speech translation. The **native macOS app is the primary codebase**;
the web/mobile apps under `mobile/` are archived (frozen, not under active development).

## Layout

- `macos/` — **active.** SwiftUI app: continuous one-way live translation (sermon/talk
  capture via mic, USB, or ScreenCaptureKit) over a Qwen realtime session. Xcode project
  generated by `xcodegen` from `macos/project.yml` (the `.xcodeproj` is NOT committed).
  See `macos/README.md` for build/run, dev-signing, and scope notes.
- `mobile/` — **archived** (tag `mobile-archive-2026-10-04`). Self-contained Node repo:
  - v1: Express server (`src/server.js`) + vanilla JS frontends (`public/`) streaming
    translations to attendees' phones.
  - v2: npm workspaces — `shared/`, `server/` (TS, :4000), `web/` (React 18 + Vite SPA).
  - All old commands work from inside `mobile/` (`npm run dev`, `npm run build:v2`, …).

## Commands (macOS app)

```bash
cd macos
xcodegen generate
xcodebuild -project LiveTranslate.xcodeproj -scheme LiveTranslate -configuration Debug build | tail
# dev deploy (stable TCC identity): ./build-and-install.sh or see dev-signing.sh
```

## Hard constraints

- **macOS app is the main target.** All new features go here unless explicitly stated
  otherwise. Do not make changes under `mobile/` unless the user asks.
- **Do not commit `macos/LiveTranslate.xcodeproj`** — regenerate with `xcodegen`.
- **Dependencies: install what you need — do not reinvent the wheel.** If a library
  exists for the job, add it (macOS: prefer SPM). `npm install` under `mobile/` may fail
  with a 403: the user's `~/.npmrc` points at a Google Artifact Registry mirror whose
  token expires hourly. **On any npm authentication failure, use the `npmrc-auth` skill**
  (repo-local copy at `.claude/skills/npmrc-auth/`): it refreshes `~/.npmrc` and
  re-authenticates via `npx --registry https://registry.npmjs.org google-artifactregistry-auth`,
  then retry the install.
- **Commit style:** `feat(macos): <summary>` / `fix(macos):` / `docs:` / `chore:`
  (for mobile work, the old `feat(v2):` style applies inside `mobile/`).
- macOS app secrets live in Keychain (DashScope key); never hardcode them.

## Testing norms

- macOS app: manual verification via build + run (no test target yet). Type-safety
  comes from Swift strict concurrency; keep models testable where practical.
- Mobile/web (archived, regression only): from `mobile/` — `npm test` (v1),
  `npm run test:v2` (vitest).
